# 更新日志

## 1.1.0

- 评分模型升级：总分改为「加权几何平均」，并采用非线性指标转换（对数 + 缩尾参考），体现六个维度之间的协调程度。
- 六个维度调整为：军事、经济、人口、领土、城市发展、国家影响力。
- 默认权重调整为 20/20/15/15/15/15，支持负值截断与旧键兼容（cities/renown）。
- 移除排行榜顶部第一名国家的详细信息展示，列表上移、可视区域扩大。
- 修复右上角 X 按钮无法关闭排行榜窗口的问题；F8 与 X 使用一致的显示状态。
- 性能优化：单趟采集城市/单位数据、排行榜行复用、异常隔离。

## 1.0.0

- 初始版本：新增综合国力排行榜。
- 算术加权和 + min-max 归一化。
- 六项指标：军队、经济、人口、城市、名望、领土。
- F8 开关，每 3 秒刷新。
